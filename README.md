# customer-financial-health-analytics

## Problem Statement
Understanding customer transaction behavior is critical for assessing financial health, reducing risk, and identifying product opportunities. This project analyzes transaction-level data to evaluate customer behvior, build a financial health scoring framework, and segment users into actionable personas.

## Dataset Overview
The dataset contains simulated transaction-level data including:
- Account identifiers
- Transaction timestamps
- Transaction amounts
- Transaction types and merchants
- Account balances

## Project Objectives
- Define meaningful account-level KPIs
- Analyze customer transaction behavior over time
- Build an explainable financial health score
- Segment customers based on behavioral patterns
- Identify early risk signals
- Translate insights into business recommendations
